# mtunzchill 🌿

Website giải trí thư giãn phong cách Cozy Cartoon (V2).

## Chạy thử

Mở `index.html` bằng trình duyệt hiện đại. Đây là bản demo frontend độc lập, không yêu cầu cài đặt hoặc cơ sở dữ liệu.

## Có gì trong bản demo?

- Trang chủ hoạt hình, chuyển ngày/đêm và hiệu ứng mưa
- Trình phát 3 giai điệu tự tổng hợp bằng Web Audio
- Bộ trộn tiếng mưa, sóng, gió
- 4 mini game: Pop Pop, Vẽ trên cát, Ghép đôi, Hồ cá
- Chọn tâm trạng, lời nhắn và tương tác với mèo Mochi
- Giao diện responsive desktop và mobile

> Bản V2 là bản thử nghiệm giao diện, chưa kết nối Render hay Neon. Các giai điệu được tổng hợp ngay trong trình duyệt, không phải danh mục nhạc thương mại.

## Triển khai

Có thể triển khai như **Static Site** trên Render với Publish Directory là thư mục gốc chứa `index.html`. Khi bổ sung backend, cần cấu hình lại kiến trúc và bảo mật phù hợp.

## Phát triển

Các phiên bản tiếp theo nên cập nhật trực tiếp repo này và kiểm thử responsive, game, âm thanh trước khi triển khai.
